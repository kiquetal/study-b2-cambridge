# Modals of Necessity: 'didn't need to' vs. 'needn't have + past participle' - Study Exercises

## Explanation Review

*   **Didn't need to (do something):** It was not necessary, and you **didn't do it**.
    *   *Example:* "I **didn't need to buy** groceries because we still had plenty of food." (I realized it wasn't necessary, so I didn't buy them.)

*   **Needn't have (done something):** You **did something**, but it turned out to be unnecessary.
    *   *Example:* "I **needn't have bought** groceries; the fridge was already full." (I bought them, but later realized it wasn't necessary.)

## Exercises - Answer Key

**Instructions:** Complete the following sentences using either 'didn't need to' or 'needn't have' with the correct form of the verb in parentheses. Pay close attention to whether the action was performed or not.

1.  I brought an umbrella, but it wasn't raining. I **needn't have brought** it.
2.  We had a lot of time, so we **didn't need to hurry**.
3.  The bus was on time, so she **didn't need to wait** for long.
4.  He studied all night for the exam, but it was very easy. He **needn't have studied** so much.
5.  They booked tickets in advance, but there were plenty available. They **needn't have booked** them.
6.  I made a lot of sandwiches for the picnic, but everyone brought their own food. I **needn't have made** so many.
7.  The shop was closed, so I **didn't need to go** there in the first place.
8.  She set her alarm, but she woke up naturally before it rang. She **needn't have set** it.
9.  We bought a new printer, but the old one started working again. We **needn't have bought** a new one.
10. It was a casual party, so you **didn't need to wear** a suit.

## Your Personal Gotchas & Key Reminders (from practice!)

*   **'Didn't need to' vs. 'Needn't have':** Always check if the action *actually happened*. If the action was performed but turned out to be unnecessary, use 'needn't have + past participle'. If the action was unnecessary and, as a result, *was not performed*, use 'didn't need to + infinitive'.
